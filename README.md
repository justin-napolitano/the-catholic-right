# The Catholic Right and JD Vance

This repository contains notes and reflections on the intersection of contemporary political figures, such as JD Vance, with Catholic theological perspectives, particularly those associated with Bishop Robert Barron. It explores theological positions, social media influence, and cultural touchpoints relevant to the Catholic right.

## Features

- Curated notes on Bishop Robert Barron's theology and its influence.
- Social media metrics related to Bishop Barron's following.
- References to cultural and political figures intersecting with Catholic thought.
- Links to external essays and resources for further exploration.

## Tech Stack

- Markdown for documentation and note-taking.
- GitHub repository for version control and collaboration.

## Getting Started

This repository primarily contains markdown notes and does not include executable code.

To view the content locally:

```bash
# Clone the repository
 git clone https://github.com/justin-napolitano/the-catholic-right.git

# Navigate into the directory
 cd the-catholic-right

# Open index.md with your preferred markdown viewer or editor
```

## Project Structure

- `index.md`: Main markdown file containing notes, reflections, and references.
